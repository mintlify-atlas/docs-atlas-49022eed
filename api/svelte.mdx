## Overview

The `@closure-next/svelte` package provides integration between Closure Next components and Svelte applications, offering a Svelte-compatible wrapper for seamless component integration.

## Installation

```bash
npm install @closure-next/svelte
```

## closureComponent

```typescript
function closureComponent<T extends Component>(
  options: ClosureComponentOptions<T>
): SvelteComponent
```

Creates a Svelte-compatible wrapper for a Closure Next component. The wrapper handles the component lifecycle, prop management, and cleanup automatically.

### Parameters

<ParamField path="options" type="ClosureComponentOptions<T>" required>
  Configuration options for the component wrapper.
  
  **Properties**:
  - `target`: HTMLElement (required) - The DOM element to render the component into
  - `component`: Component constructor (required) - The Closure Next component class
  - `props`: Record\<string, unknown\> (optional) - Initial props for the component
</ParamField>

### Returns

<ResponseField name="wrapper" type="SvelteComponent">
  A Svelte component instance that wraps the Closure Next component. The wrapper extends `SvelteComponent` and includes:
  - Standard Svelte lifecycle methods
  - Automatic cleanup via `$destroy()`
  - Component reference stored on the target element as `_closureComponent`
</ResponseField>

### Type Definition

```typescript
interface ClosureComponentOptions<T extends Component> {
  target: HTMLElement;
  props?: Record<string, unknown>;
  component: new () => T;
}
```

### Behavior

1. **Initialization**: Creates a new instance of the Closure component
2. **Rendering**: Calls `render()` on the component with the target element
3. **Props Application**: 
   - Attempts to call setter methods (e.g., `setTitle` for a `title` prop)
   - Falls back to direct property assignment or method calls
4. **Lifecycle**: Stores component reference on target element for debugging and testing
5. **Cleanup**: Automatically disposes the component when `$destroy()` is called

### Example

```svelte
<script lang="ts">
  import { closureComponent } from '@closure-next/svelte';
  import { MyClosureComponent } from './my-component';
  
  let target: HTMLElement;
  
  const component = closureComponent({
    target,
    component: MyClosureComponent,
    props: {
      title: 'Hello from Closure Next',
      onClick: () => alert('Clicked!')
    }
  });
  
  // Component is automatically destroyed when this Svelte component is destroyed
</script>

<div bind:this={target}></div>
```

### Advanced Usage

#### With Reactive Props

```svelte
<script lang="ts">
  import { onMount } from 'svelte';
  import { closureComponent } from '@closure-next/svelte';
  import { Button } from '@closure-next/core';
  
  let buttonTarget: HTMLElement;
  let label = 'Click me';
  let component: any;
  
  onMount(() => {
    component = closureComponent({
      target: buttonTarget,
      component: Button,
      props: {
        label,
        onClick: () => alert('Button clicked!')
      }
    });
  });
  
  // Update props when reactive value changes
  $: if (component && buttonTarget) {
    const closureInstance = (buttonTarget as any)._closureComponent;
    if (closureInstance && closureInstance.setLabel) {
      closureInstance.setLabel(label);
    }
  }
</script>

<div>
  <input bind:value={label} />
  <div bind:this={buttonTarget}></div>
</div>
```

#### Accessing Component Instance

```svelte
<script lang="ts">
  import { onMount } from 'svelte';
  import { closureComponent } from '@closure-next/svelte';
  import { MyClosureComponent } from './my-component';
  
  let target: HTMLElement;
  let closureInstance: MyClosureComponent;
  
  onMount(() => {
    const wrapper = closureComponent({
      target,
      component: MyClosureComponent,
      props: { title: 'Hello' }
    });
    
    // Access the Closure component instance
    closureInstance = (target as any)._closureComponent;
    
    return () => {
      wrapper.$destroy();
    };
  });
  
  function updateTitle() {
    if (closureInstance) {
      closureInstance.setTitle('Updated Title');
    }
  }
</script>

<div>
  <button on:click={updateTitle}>Update</button>
  <div bind:this={target}></div>
</div>
```

## Props Handling

### Setter Method Priority

The integration attempts to set props in the following order:

1. **Setter methods**: Looks for methods like `setTitle()` for a `title` prop
2. **Function properties**: If the property is a function, calls it with the value
3. **Direct assignment**: Falls back to direct property assignment

```typescript
class MyComponent extends Component {
  private _title: string = '';
  
  // This setter will be called for the 'title' prop
  setTitle(title: string): void {
    this._title = title;
    if (this.element) {
      this.element.textContent = title;
    }
  }
}

// Usage
closureComponent({
  target,
  component: MyComponent,
  props: {
    title: 'Hello' // Calls setTitle('Hello')
  }
});
```

## Component Lifecycle

### Initialization Flow

1. Component constructor is called: `new ComponentClass()`
2. Component is rendered: `component.render(target)`
3. Props are applied using setter methods or direct assignment
4. Component reference is stored on target element

### Cleanup Flow

1. `$destroy()` is called on the Svelte wrapper
2. `dispose()` is called on the Closure component
3. Component reference is removed from target element
4. Standard Svelte cleanup continues

### Example Lifecycle Integration

```svelte
<script lang="ts">
  import { onMount, onDestroy } from 'svelte';
  import { closureComponent } from '@closure-next/svelte';
  import { MyComponent } from './my-component';
  
  let target: HTMLElement;
  let wrapper: any;
  
  onMount(() => {
    console.log('Svelte component mounting');
    
    wrapper = closureComponent({
      target,
      component: MyComponent,
      props: { /* ... */ }
    });
    
    console.log('Closure component initialized');
  });
  
  onDestroy(() => {
    console.log('Svelte component destroying');
    
    if (wrapper) {
      wrapper.$destroy();
    }
    
    console.log('Closure component disposed');
  });
</script>

<div bind:this={target}></div>
```

## Best Practices

### Use Svelte's Lifecycle Hooks

Initialize Closure components in `onMount` to ensure the DOM is ready:

```svelte
<script lang="ts">
  import { onMount } from 'svelte';
  
  let target: HTMLElement;
  
  onMount(() => {
    const component = closureComponent({
      target,
      component: MyComponent,
      props: { /* ... */ }
    });
    
    // Return cleanup function
    return () => component.$destroy();
  });
</script>
```

### Define Clear Setter Methods

Implement setter methods in your Closure components for better prop handling:

```typescript
class MyComponent extends Component {
  private _title: string = '';
  private _count: number = 0;
  
  setTitle(title: string): void {
    this._title = title;
    this.updateDOM();
  }
  
  setCount(count: number): void {
    this._count = count;
    this.updateDOM();
  }
  
  private updateDOM(): void {
    if (this.element) {
      this.element.innerHTML = `${this._title}: ${this._count}`;
    }
  }
}
```

### Handle Component References Carefully

Store component references when you need programmatic access:

```svelte
<script lang="ts">
  import { onMount } from 'svelte';
  
  let target: HTMLElement;
  let componentRef: MyComponent | null = null;
  
  onMount(() => {
    closureComponent({ target, component: MyComponent });
    componentRef = (target as any)._closureComponent;
  });
  
  function callComponentMethod() {
    componentRef?.someMethod();
  }
</script>
```

### Cleanup on Component Destruction

Always ensure proper cleanup to avoid memory leaks:

```svelte
<script lang="ts">
  import { onDestroy } from 'svelte';
  
  let wrapper: any;
  
  onDestroy(() => {
    // Svelte wrapper cleanup (also calls dispose on Closure component)
    wrapper?.$destroy();
    
    // Additional custom cleanup if needed
    // ...
  });
</script>
```

### Testing

Access the component instance in tests via the stored reference:

```typescript
import { render } from '@testing-library/svelte';
import MyComponent from './MyComponent.svelte';

test('closure component integration', () => {
  const { container } = render(MyComponent);
  const target = container.querySelector('[data-closure-target]');
  const closureComponent = (target as any)?._closureComponent;
  
  expect(closureComponent).toBeDefined();
  expect(closureComponent.getElement()).toBeTruthy();
});
```
