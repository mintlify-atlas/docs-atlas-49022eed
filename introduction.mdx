# Welcome to Closure Next

**Closure Next** is a modern and optimized reimagining of the iconic [Google Closure Library](https://github.com/google/closure-library), rewritten from the ground up in **TypeScript** for the modern JavaScript ecosystem.

Built for performance, modularity, and developer experience, Closure Next brings the battle-tested patterns of Closure Library to React, Vue, Angular, Svelte, and beyond — with first-class support for modern build tools like Webpack, Vite, and Rollup.

## Why Closure Next?

The original Google Closure Library powered some of the web's largest applications, including Gmail and Google Docs. Closure Next brings those proven architectural patterns into the modern era:

- **Type Safety**: Full TypeScript support means catching bugs at compile time, not runtime
- **Modern APIs**: Clean, intuitive APIs designed for 2020s JavaScript development
- **Zero Legacy**: No compromises for backwards compatibility — built fresh for modern platforms
- **Modular Design**: Import only what you need for optimal bundle sizes
- **Active Development**: Regular updates, modern dependencies, and an engaged community

## Quick Example

```typescript
import { Component, DOMHelper } from '@closure-next/core';

class HelloWorld extends Component {
  constructor() {
    super(new DOMHelper());
  }

  protected async createDom(): Promise<void> {
    this.element = this.domHelper.createElement('div');
    this.element.textContent = 'Hello, Closure Next!';
  }
}

const component = new HelloWorld();
await component.render(document.body);
```
